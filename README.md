# Технікал Геймз

Збірка маленьких браузерних ігор в одному файлі. Без збірки, без залежностей, без сервера.

**Грати:** https://ramen-ichiraku.github.io/karas-tikaye/

Стартова сторінка — каталог із картками. Кожна картка має живу мініатюру, що малюється на `<canvas>`. Гра запускається в тій самій вкладці й повертається в каталог кнопкою «← Ігри». На гру можна дати пряме посилання через хеш: `…/#karas` і `…/#karas2` відкривають її одразу.

## Ігри

### Карась Тікає

Раннер у три ряди. Карась на ногах збирає монети, ухиляється від перешкод і тікає від чорного буса.

| Дія | Клавіатура | Телефон |
| --- | --- | --- |
| Змінити ряд | `←` `→` або `A` `D` | свайп вліво/вправо |
| Стрибок | `↑`, `W` або пробіл | свайп вгору або тап |
| Підкат | `↓` або `S` | свайп вниз |
| Пауза | `Esc` або `P` | кнопка «Пауза» |

Перешкоди: **бак** — оббігти сусіднім рядом (точний стрибок теж рятує), **калюжа** — стрибок, **шлагбаум** — підкат.

Смужка «Бус» зверху показує дистанцію до переслідувача. Зіткнення підпускає його ближче й збиває швидкість, монети та чистий біг відривають. Розминутися з перешкодою впритул — невеликий бонус, кожні 500 м — відчутний.

### Карась 2: Несамовита слють

Вид зверху. Орда зомбі й прибульців суне з усіх боків, карась відбивається.

| Дія | Клавіатура | Телефон |
| --- | --- | --- |
| Рух | `WASD` або стрілки | джойстик: торкнись будь-де й тягни |
| Приціл | миша | автоматично по найближчому |
| Удар | автоматичний | автоматичний |
| Вибір апгрейда | `1` `2` `3` | тап по картці |
| Пауза | `Esc` або `P` | кнопка «Пауза» |

**Зброя на вибір перед забігом.** *Плями* б'ють на відстань: безпечніше, але треба влучати. Масштабуються через кількість плям за постріл, купність і пробивання наскрізь. *Розочка* — розбита пляшка, косить по дузі впритул: більше шкоди за секунду й одразу по кількох, але дістає лише трохи далі, ніж дістають тебе.

**Вороги.** Зомбі повільні й живучі, шкандибають ривками. Прибульці слабкі, але з кожною хвилею швидшають і з дев'ятої вже бігають швидше за карася — від них не втекти, тільки відстріляти. Еліта з четвертої хвилі: велика, товста, б'є найболючіше.

Усі б'ють однаково — **тазом**. Увійшовши в контакт, ворог відводить таз назад і доводить замах; удар зараховується на піку виносу. Вийти із зони до завершення замаху — значить не отримати шкоди.

**Розвиток.** Хвиля міняється кожні 22 секунди: ворогів за раз більше, інтервал між появами коротший, а живучість орди росте квадратично — тому будь-яка прокачка рано чи пізно не витримує. Кожні 15 убитих гра стає на паузу й пропонує три апгрейди на вибір. З десятої частини трупів випадає аптечка на 18 життя.

## Баланс

Зводився ботом у headless-прогоні, не на око:

| Хто грає | Скільки живе | Доходить до |
| --- | --- | --- |
| Стоїть на місці | ~61 с | хвиля 3 |
| Бот, плями: тікає й бере бойові апгрейди | ~140 с | хвиля 7 |
| Бот, розочка: лізе в гущу, шарахається лише впритул | ~89 с | хвиля 5 |

Нерухомість карається за хвилину, обидві зброї дають близький рахунок за секунду, і жодна не тягне нескінченно.

Квадратична живучість тут не прикраса. Апгрейди множаться по незалежних осях (швидкість × шкода × кількість × пробивання), і за лінійного росту ворогів прокачаний гравець ставав невразливим — у прогоні обидві зброї переживали 400 секунд, не помітивши орди.

## Як додати гру

Гра — це фабрика, яка монтується в переданий контейнер і вміє прибрати за собою:

```js
function createMyGame(root){
  root.innerHTML = MY_TPL;      // власна розмітка: полотно, HUD, екрани
  var AB = new AbortController();
  // слухачі реєструються з { signal: AB.signal }
  // цикл кадрів тримає свій rafId
  function stop(){
    cancelAnimationFrame(rafId);
    AB.abort();                 // знімає всі слухачі одним рухом
    if (AC) AC.close();         // звільняє аудіоконтекст
    root.innerHTML = '';
  }
  return { stop: stop };
}
```

Далі — один запис у масиві `GAMES`:

```js
{
  id: 'mygame',                 // він же токен для посилання виду #mygame
  title: 'Назва',
  lede: 'Одне речення про те, що це таке.',
  chips: ['Жанр', 'Керування'],
  bestKey: 'mygame.best',       // ключ рекорду в localStorage, показується на картці
  create: createMyGame,
  thumb: thumbMyGame            // thumb(ctx, w, h, t) — малює мініатюру, t у секундах
}
```

Оболонка сама побудує картку, запустить мініатюру, змонтує гру, обробить хеш і вихід у каталог.

Контракт короткий, але його варто дотримати повністю. Якщо гра не зніме слухачі або не зупинить свій `requestAnimationFrame`, вона продовжить крутитися у фоні після виходу в каталог — і другий запуск піде поверх першого.

Ідентифікатори в розмітці гри мають бути власні (у другої гри всі з префіксом `k2`).

### Клавіші

Читай `e.code`, а не `e.key`. На українській розкладці фізичні W/A/S/D дають `ц`, `ф`, `і`, `в` — гра з перевіркою по `e.key` мовчки лишається без WASD, і працюють тільки стрілки. Обидві ігри мають `keyTok(e)`, який бере `e.code`, а за його відсутності розбирає `e.key` разом із кириличними символами.

## Як влаштовано

Один самодостатній `index.html`: оболонка, стилі й усі ігри в одному файлі. Графіка малюється процедурно на `<canvas>` — карась, дорога, бус, зомбі та прибульці намальовані кодом, жодних спрайтів.

Звук і музика повністю синтезовані через Web Audio API, без аудіофайлів. У першій грі — чіптюн у ля-мінорі, темп якого росте разом із небезпекою; у другій — злий фрігійський риф, що прискорюється з хвилями. Кожна гра тримає власний аудіоконтекст і закриває його на виході.

Рекорди й налаштування звуку зберігаються в `localStorage` і нікуди не надсилаються. Ззовні тягнуться лише шрифти з Google Fonts; без інтернету все працює, просто системним шрифтом.

## Запуск локально

Відкрити `index.html` подвійним кліком у будь-якому браузері. Сервер не потрібен.
