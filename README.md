# Карась Тікає

Веб-раннер у три ряди. Карась на ногах збирає монети, ухиляється від перешкод і тікає від чорного буса.

**Грати:** https://ramen-ichiraku.github.io/karas-tikaye/

## Керування

| Дія | Клавіатура | Телефон |
| --- | --- | --- |
| Змінити ряд | `←` `→` або `A` `D` | свайп вліво/вправо |
| Стрибок | `↑`, `W` або пробіл | свайп вгору або тап |
| Підкат | `↓` або `S` | свайп вниз |
| Пауза | `Esc` або `P` | кнопка «Пауза» |

## Перешкоди

- **Бак** — оббігти сусіднім рядом (точний стрибок теж рятує).
- **Калюжа** — стрибок.
- **Шлагбаум** — підкат.

Смужка «Бус» зверху показує дистанцію до переслідувача. Зіткнення підпускає його ближче й збиває швидкість, монети та чистий біг відривають. З часом відрив дається важче.

## Як влаштовано

Один самодостатній `index.html`: розмітка, стилі й гра в одному файлі, без збірки та залежностей. Графіка малюється процедурно на `<canvas>` у псевдо-3D перспективі — карась, дорога, перешкоди й бус намальовані кодом, жодних спрайтів. Звук — синтезований через Web Audio API, вимкнений за замовчуванням. Рекорд зберігається в `localStorage`.

Ззовні тягнуться лише шрифти з Google Fonts; без інтернету гра працює, просто системним шрифтом.

## Запуск локально

Відкрити `index.html` подвійним кліком у будь-якому браузері. Сервер не потрібен.
